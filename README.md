# Monzón Álvaro — Fotografía & Video

Sitio web estático, listo para publicar en GitHub Pages o Cloudflare Pages.

## Antes de publicar

1. Abrí `assets/js/config.js`.
2. Completá `WhatsApp` con el número en formato internacional, sin `+`, espacios ni guiones. Ejemplo: `5493456123456`.
3. Completá `email` si querés mostrar correo.
4. Reemplazá las imágenes SVG de `assets/img/` por tus fotografías reales, manteniendo los nombres o actualizando las rutas de `index.html`.
5. Si elegís otro dominio, cambiá la URL canónica de `index.html`, `robots.txt` y `sitemap.xml`.

## Publicación gratuita

### GitHub Pages
Subí el contenido de esta carpeta a un repositorio público y activá Pages desde Settings → Pages. GitHub Pages permite publicar sitios estáticos y usar un dominio propio.

### Cloudflare Pages
Conectá el repositorio o subí el sitio como proyecto estático. Cloudflare Pages genera una URL `pages.dev` y permite agregar un dominio propio.

## Galerías de clientes

La web pública está separada del almacenamiento de galerías. El botón `Mi galería` muestra actualmente un aviso hasta que se conecte tu proveedor de galerías. Esto evita publicar una URL falsa.
